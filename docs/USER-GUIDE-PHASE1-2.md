## 0. ภาพรวม
Mommunjai คือเครื่องมือของแบรนด์ **Baby & Mom+ (ครูก้อย)** สำหรับ:
1. **หาลูกค้าใหม่ (lead):** ให้คนทั่วไปใช้เครื่องมือฟรี 5 อย่าง → กรอกแบบสอบถามสั้น ๆ → ได้ **"แผน 90 วัน ฉบับของตัวเอง"** ทันที → ทีมได้เบอร์/LINE ของเขาพร้อมเลขตั๋ว (ticket)
2. **ดูแลลูกค้าต่อ:** ทีมงานเห็นข้อมูลลูกค้าแต่ละคน ใส่แท็ก คุยต่อทาง LINE ได้ทันที

ระบบแบ่งเป็น 2 ฝั่งที่ทดลองแยกกันได้:
| ฝั่ง | ใครใช้ | เข้าทางไหน |
|---|---|---|
| **ลูกค้า (เฟส 1)** | คนทั่วไปที่สนใจเตรียมตั้งครรภ์ | หน้าเว็บปกติ ไม่ต้อง login |
| **ทีมงาน (เฟส 2)** | ครูก้อย/แอดมิน/staff | ต้อง login ด้วยชื่อผู้ใช้ + PIN |

## 1. ฝั่งลูกค้า
### 1.1 หน้าแรก
🔗 **https://mommunjai-dev.vercel.app**
เห็นโลโก้ Baby & Mom+ + เครื่องมือ 5 อย่าง + ปุ่ม "รับคำแนะนำเฉพาะคุณ"

### 1.2 เครื่องมือฟรี 5 อย่าง (ใช้ได้ทันที ไม่ต้องกรอกอะไรก่อน)
| เครื่องมือ | ลิงก์ | ทำอะไร |
|---|---|---|
| 📅 นับวันไข่ตก | `/tools/ovulation` | กรอกวันแรกของประจำเดือน + ความยาวรอบเดือน → ได้ช่วงวันที่มีโอกาสตั้งครรภ์สูงสุด |
| 🥚 คำนวณโปรตีน | `/tools/protein` | กรอกน้ำหนักตัว + ช่วงชีวิต → ได้ปริมาณโปรตีนที่ควรกินต่อวัน (เป็นช่วง เช่น 78–98 กรัม) |
| 🥗 เช็กสารอาหาร | `/tools/nutrients` | เช็กว่าสารอาหารหลักที่กินวันนี้ครบตามหลักโภชนาการไหม |
| 🌙 คำนวณการนอน | `/tools/sleep` | หาช่วงเวลานอนที่ดีต่อฮอร์โมนเจริญพันธุ์ |
| 💊 แนะนำวิตามินครูก้อย | `/tools/vitamins` | ตอบคำถามสั้น ๆ → ได้วิตามินที่ตรงกับช่วงชีวิต/อาการ |

ทุกเครื่องมือมี **คำเตือน (disclaimer)** กำกับเสมอว่าไม่แทนคำวินิจฉัยแพทย์ และผลจากเครื่องมือจะถูกจดจำไว้ (ในเบราว์เซอร์ผู้ใช้เอง) เพื่อนำไปใช้ต่อตอนทำแบบสอบถามข้อ 1.3

### 1.3 แบบสอบถาม → รับ "แผน 90 วัน ฉบับของคุณ"
🔗 **https://mommunjai-dev.vercel.app/plan**
นี่คือหัวใจของการหา lead — ออกแบบให้กรอกจบง่าย (6 หน้าจอ ทีละหัวข้อ):
1. คำทัก + เกริ่นสั้น ๆ
2. ชื่อเล่น
3. ช่วงชีวิต (เตรียมท้อง/มีบุตรยาก/ตั้งครรภ์แล้ว/ให้นม/ฝ่ายชาย)
4. คำถามสุขภาพที่เกี่ยวข้อง (เช่น PCOS)
5. แผนการรักษา (ถ้ามี ART/IUI/IVF/ICSI)
6. ช่องทางติดต่อ (LINE/เบอร์โทร) + ติ๊กยินยอมให้เก็บข้อมูล (PDPA)

กด **"ดูแผนของฉัน"** → ระบบจะ:
- ออก **เลขตั๋ว (ticket)** รูปแบบ `MJ-XXXXXX` ให้ทันที
- แสดง **รายงานฉบับเต็ม** ในหน้าเดียวกัน: จุดแข็งก่อน → คะแนนความพร้อม (นุ่มนวล ไม่ตัดสิน) → แผน 90 วัน 3 ช่วง → สินค้าที่แนะนำ (70% อาหาร/30% วิตามิน) → 3 อย่างที่ทำได้สัปดาห์นี้ → ชวนคู่มาเช็คด้วย

### 1.4 รายงานแชร์ต่อได้
🔗 **https://mommunjai-dev.vercel.app/r/MJ-XXXXXX** (ใส่เลขตั๋วจริงที่ได้จากข้อ 1.3)
เปิดได้จากมือถือ/คอมพิวเตอร์เครื่องไหนก็ได้ ไม่ต้อง login — ใช้เลขตั๋วเป็นกุญแจ (เหมาะสำหรับส่งลิงก์นี้เข้า LINE ให้ลูกค้าเปิดดูซ้ำได้)

## 2. ฝั่งทีมงาน
### 2.1 ตั้งค่าครั้งแรก — สร้างบัญชี Admin
🔗 **https://mommunjai-dev.vercel.app/login**
ถ้ายังไม่เคยมีผู้ใช้เลย ระบบจะขึ้นหน้า **"ตั้งค่าผู้ดูแลระบบคนแรก"** อัตโนมัติ — กรอกชื่อผู้ใช้ + ชื่อที่แสดง + ตั้ง PIN (≥4 หลัก) แล้วกด "สร้าง Admin" **ทำได้ครั้งเดียวเท่านั้น** (ผู้ใช้คนถัดไปต้องให้ Admin สร้างให้จากหน้า `/admin`)

### 2.2 หน้าค้นหา Ticket (staff ทุกคนใช้ได้)
🔗 **https://mommunjai-dev.vercel.app/staff**
พิมพ์เลขตั๋ว `MJ-XXXXXX` → เห็นข้อมูลลูกค้าคนนั้นทั้งหมด: ชื่อเล่น, ช่องทางติดต่อ, ช่วงชีวิต, อายุ, PCOS, แผน ART, คะแนนความพร้อม, สถานะเชื่อม LINE, แท็กทั้งหมด, ลิงก์ดูรายงานฉบับเต็ม, รายชื่อเครื่องมือที่เขาเคยใช้
ถ้ามีสิทธิ์ **จัดการ Tag** จะเพิ่มแท็กเองได้ (เช่น พิมพ์ "พร้อมซื้อ" แล้วกดเพิ่ม)

### 2.3 Leads Dashboard — ดูรายชื่อทั้งหมด
🔗 **https://mommunjai-dev.vercel.app/leads** (ต้องมีสิทธิ์ **ดูข้อมูลลูกค้า/Ticket**)
ตารางรายชื่อลูกค้าทุกคนที่เคยกรอกแบบสอบถาม พร้อมตัวกรอง: ค้นหาชื่อ/รหัสตั๋ว · ช่วงชีวิต · PCOS · แผน ART · แท็ก · สถานะเชื่อม LINE — คลิกแถวไหนก็เปิดไปหน้าค้นหา Ticket (2.2) ของคนนั้นทันที
ถ้ามีสิทธิ์ **ส่งออกข้อมูล** จะมีปุ่มดาวน์โหลดเป็น CSV (ใช้เปิดใน Excel ได้)

### 2.4 จัดการผู้ใช้ทีมงาน (Admin เท่านั้น)
🔗 **https://mommunjai-dev.vercel.app/admin**
Admin สร้างบัญชี staff ใหม่ได้เอง: ตั้งชื่อผู้ใช้ + ชื่อที่แสดง + PIN + เลือกว่าเป็น staff หรือ admin
ถ้าเป็น **staff** จะเลือกสิทธิ์ได้เป็นรายอย่าง (ติ๊กได้หลายอัน):
| สิทธิ์ | ทำอะไรได้ |
|---|---|
| ดูข้อมูลลูกค้า/Ticket | เข้า `/leads` และค้นหา ticket ได้ |
| จัดการ Tag | เพิ่ม/ลบแท็กให้ลูกค้าได้ |
| ดูรายงานเฉพาะบุคคล | เปิดดูรายงาน 90 วันของลูกค้าได้ |
| จัดการผู้ใช้ (Admin) | สร้าง/ปิดผู้ใช้คนอื่นได้ (ปกติให้เฉพาะ Admin) |
| ตั้งค่า LINE | ดู/ตั้งค่าการเชื่อมต่อ LINE OA |
| ส่งออกข้อมูล | ดาวน์โหลด CSV ได้ |

จากหน้านี้ยังรีเซ็ต PIN หรือปิดการใช้งานบัญชีใครก็ได้ (ไม่ต้องลบทิ้ง)

## 3. LINE OA
ระบบเชื่อมกับ LINE OA ของครูก้อยแล้ว (ตรวจสอบผ่าน `/api/health` ล่าสุด: **พร้อมใช้งาน ✅**) — เมื่อลูกค้าพิมพ์เลขตั๋ว `MJ-XXXXXX` เข้าไปในแชท LINE OA ระบบจะ:
1. ผูกบัญชี LINE ของเขากับเลขตั๋วอัตโนมัติ
2. ติดแท็ก `#line-connected` ให้เอง
3. ตอบกลับด้วยการ์ดสรุปรายงาน (คะแนน + 3 อันดับแรก + ปุ่มดูฉบับเต็ม)

> 📌 หน้าค้นหา Ticket (2.2) จะขึ้น 🟢 "เชื่อม LINE แล้ว" ทันทีที่ผูกสำเร็จ — ใช้ตรงนี้ยืนยันว่า LINE ทำงานถูกต้อง

## 4. เช็กลิสต์ทดลองใช้ (ทำตามลำดับ ~15 นาที)
- [ ] **1.** เปิดหน้าแรก ลองกด "เริ่มใช้เครื่องมือ" แล้วลองเล่น 2–3 เครื่องมือ (เช่น นับวันไข่ตก + คำนวณโปรตีน)
- [ ] **2.** กด "รับคำแนะนำเฉพาะคุณ" → กรอกแบบสอบถามจนจบ (ใช้ข้อมูลสมมติได้) → **จดเลขตั๋วที่ได้ไว้**
- [ ] **3.** อ่านรายงานที่ได้ — เช็คว่าน้ำเสียง/เนื้อหาตรงกับที่แบรนด์อยากสื่อไหม
- [ ] **4.** เปิดลิงก์รายงาน `/r/เลขตั๋ว` จากอุปกรณ์อีกเครื่อง (เช่น มือถือ) — ต้องเปิดได้โดยไม่ต้อง login
- [ ] **5.** เข้า `/login` → ตั้งบัญชี Admin คนแรก (ถ้ายังไม่มี)
- [ ] **6.** เข้า `/staff` → ค้นหาเลขตั๋วจากข้อ 2 → ดูว่าข้อมูลที่กรอกไว้ขึ้นครบไหม → ลองเพิ่มแท็ก 1 อัน
- [ ] **7.** เข้า `/leads` → ดูว่ารายชื่อจากข้อ 2 ขึ้นในตารางไหม → ลองใช้ตัวกรอง
- [ ] **8.** เข้า `/admin` → ลองสร้างบัญชี staff ทดสอบ 1 คน พร้อมเลือกสิทธิ์แค่บางอย่าง → login ด้วยบัญชีนั้นดูว่าเห็นเฉพาะที่ให้สิทธิ์จริงไหม
- [ ] **9.** (ถ้ามี LINE OA ทดสอบ) เพิ่มเพื่อน OA แล้วพิมพ์เลขตั๋วจากข้อ 2 เข้าไปในแชท → เช็คว่าได้การ์ดสรุปตอบกลับ + หน้า `/staff` ขึ้น 🟢 เชื่อม LINE แล้ว

## 5. ข้อจำกัด/สิ่งที่ควรรู้ก่อนทดลอง
- 🔧 **นี่คือ dev/staging environment** ไม่ใช่โดเมนจริงของแบรนด์ — ข้อมูลที่กรอกทดสอบเป็นข้อมูลจริงในฐานข้อมูล ไม่ใช่ mock กรุณา**อย่าใช้ข้อมูลส่วนตัวจริงของคนอื่น** ในการทดสอบ
- 💊 **เกณฑ์คะแนนในรายงาน (0–100) เป็นตัวเลขที่ทีมพัฒนาตั้งขึ้นเพื่อให้ระบบทำงานได้ก่อน** ยังไม่ผ่านการตรวจสอบจากเภสัชกร/แพทย์ — ห้ามใช้ตัดสินใจทางการแพทย์จริง และควรให้ผู้เชี่ยวชาญของแบรนด์ตรวจก่อนใช้กับลูกค้าจริง
- 📦 สินค้าที่แนะนำในรายงานอ้างจาก `product-catalog-master.md` (ฉบับร่าง) — ราคา/สถานะ อย. ต้องให้ทีมครูก้อยยืนยันอีกครั้งก่อนเผยแพร่จริง
- 🔐 การเชื่อมต่อ LINE OA ที่ใช้ทดสอบตอนนี้เป็น **LINE OA ทดสอบ** ตามที่ต้นแจ้งไว้ ไม่ใช่ OA ตัวจริงที่มีฐานลูกค้า 150,000 คน
- 📱 ทดสอบบนมือถือได้เลย ระบบออกแบบมือถือก่อน (mobile-first) แต่ก็ใช้บนคอมพิวเตอร์ได้ปกติ

## 6. ส่ง feedback อย่างไร
ระหว่างทดลองใช้ ถ้าเจออะไรที่: อยากให้ปรับคำพูด/น้ำเสียง, มีจุดที่งง/กรอกยาก, อยากได้ฟีเจอร์เพิ่ม, หรือเจอ error ใด ๆ — โน้ตไว้พร้อม **เลขตั๋วหรือชื่อหน้าที่เจอปัญหา** แล้วส่งกลับมาให้ทีมพัฒนาปรับได้ทันที
