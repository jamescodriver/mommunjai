## 0. ทำไมต้องแนวนี้ (ไม่ใช่แค่ "อยากให้สวย")

กติกาจากฐานข้อมูล UI/UX สำหรับ 3 หมวดที่ตรงกับแอปนี้:

| หมวด | สไตล์ที่แนะนำ | สิ่งที่ห้าม |
|---|---|---|
| **Healthcare App** | Neumorphism + Accessible & Ethical · เงานุ่ม · กดแล้วตอบ 150ms · ตัวอักษร 16px+ | สีนีออนจัด · แอนิเมชันเยอะ · gradient ม่วง-ชมพูแบบ AI |
| **Mental Health App** | Neumorphism + Accessible & Ethical · **พาสเทลสงบ** | สีนีออน · motion เยอะเกิน |
| **Beauty/Wellness** | Soft UI Evolution · พาสเทลนุ่ม · เงานุ่ม + transition 200–300ms | สีนีออน · แอนิเมชันกระด้าง · dark mode |

**สรุปทิศทาง:** *Soft UI (neumorphism อ่อน ๆ) + พาสเทลสงบ + มุมโค้งเยอะ + กดแล้วนุ่ม*

> 🔴 **เหตุผลที่ลึกกว่าความสวย:** กลุ่มผู้ใช้คือคนที่กำลังพยายามมีลูก/มีบุตรยาก ซึ่งเปราะบางทางอารมณ์
> (ดู `legal-compliance.md` §4 ห้ามขายความกลัว) — UI ที่กระด้าง สีจัด หรือแอนิเมชันเร้าใจ
> ไม่ใช่แค่ "ไม่สวย" แต่ **ขัดกับหน้าที่ของแอปโดยตรง** ความสงบคือฟีเจอร์ ไม่ใช่รสนิยม

## 1. โทเคนหลัก

### 1.1 ความโค้ง (หัวใจของลุคนี้)
FLO โค้งเยอะกว่าแอปทั่วไปมาก — นี่คือสิ่งที่ทำให้ "ดูนุ่ม" ตั้งแต่แรกเห็น

| ใช้กับ | ค่า |
|---|---|
| การ์ดใหญ่ | **28** |
| การ์ดย่อย / ผลลัพธ์ | **20** |
| ช่องกรอก | **18** |
| ปุ่ม | **999** (แคปซูลเต็ม) |
| ช่องติ๊ก | **10** |
| ชิป/แท็ก | **999** |

### 1.2 เงา — นุ่ม ฟุ้ง ไม่คม
```
soft   : opacity .05 · radius 16 · offset y 4     ← การ์ดทั่วไป
lifted : opacity .07 · radius 24 · offset y 8     ← การ์ดเด่น/ลอย
```
> ห้ามใช้เงาเข้ม/ขอบคม — จะกลายเป็น Material ไม่ใช่ FLO

### 1.3 พื้นผิว — พาสเทลแทนขาวโพลน
พื้นหลังแอปเป็นครีมอมชมพูจาง ๆ ไม่ใช่ `#FFF` เพราะขาวล้วนกับการ์ดขาวจะแบนและแสบตา

| โทเคน | ค่า | ใช้กับ |
|---|---|---|
| `bg` | `#FDF9FB` | พื้นหลังแอป (ครีมอมชมพู) |
| `surface` | `#FFFFFF` | การ์ด |
| `tealSoft` | `#E6F7F6` | การ์ดข้อมูล/ผลลัพธ์ |
| `roseSoft` | `#FFE7F1` | การ์ดเน้น/ช่วงมีโอกาส |
| `lavender` | `#F0EDFB` | พื้นผิวรอง (พักสายตา) |
| `cream` | `#FFF6E9` | คำเตือน/โน้ต |

### 1.4 ตัวอักษร
ยึด 16px+ ตามกฎ Healthcare (อ่านง่ายสำคัญกว่าสวยเนี้ยบ) · ภาษาไทยต้องการ line-height สูงกว่าอังกฤษเพราะมีสระบน-ล่าง

| ระดับ | ขนาด / line-height |
|---|---|
| ตัวเลขใหญ่ (ในวงแหวน) | 44 / 52 |
| หัวข้อใหญ่ | 24 / 36 |
| หัวข้อการ์ด | 19 / 30 |
| เนื้อความ | 16 / 27 |
| รอง | 14 / 23 |
| เล็กสุด | 12.5 / 20 |

### 1.5 การกด (micro-interaction)
```
กดค้าง  → scale 0.97 + opacity .9   (150ms)
ปล่อย   → กลับ 1.0                  (150ms)
```
> ทุกอย่างที่กดได้ต้องตอบสนอง — FLO ทำให้ทุกการแตะรู้สึก "นุ่มแต่มีชีวิต"
> เคารพ `prefers-reduced-motion` เสมอ

## 2. องค์ประกอบเอกลักษณ์: วงแหวนรอบเดือน

หน้าแรกของ FLO คือ **วงแหวนใหญ่** — เป็นสิ่งที่จำได้ทันทีและสื่อ "จังหวะของร่างกาย" ได้ในภาพเดียว

แอปเรามีข้อมูลรอบเดือนอยู่แล้ว จึงใช้ได้ตรง ๆ:

```
        ╭───────────────╮
      ╱   วันที่ 12 ของ   ╲      ← วงนอก = ทั้งรอบ (สีจาง)
     │      รอบเดือน       │     ← ส่วนโค้งเข้ม = วันที่ผ่านมาแล้ว
     │   ช่วงมีโอกาส       │     ← ส่วนโค้งชมพู = ช่วงมีโอกาส
      ╲    อีก 3 วัน     ╱      ← จุดเล็ก = วันนี้
        ╰───────────────╯
```

**ปรับตามช่วงชีวิต (ไม่ใช่ทุกคนมีรอบเดือน):**

| ช่วงชีวิต | วงแหวนแสดงอะไร |
|---|---|
| เตรียมตั้งครรภ์ · มีบุตรยาก | รอบเดือน + ช่วงมีโอกาส (ชมพู) |
| ตั้งครรภ์แล้ว | ความคืบหน้าอายุครรภ์ (40 สัปดาห์) |
| ให้นมบุตร · ฝ่ายชาย | ความคืบหน้าแผน 90 วัน |

🔴 ถ้าข้อมูลไม่พอ → วงแหวนเป็นเส้นจาง ๆ พร้อมชวนกรอก **ห้ามวาดวงเต็มหลอก ๆ หรือโชว์ 0**

## 3. ไอคอน — เลิกใช้ emoji

**ปัญหาเดิม:** ใช้ emoji (🏠🧮📅👤💧🥚) เป็นไอคอน ซึ่ง checklist ของ `/ui-ux-pro-max` ห้ามชัดเจน

ทำไมถึงสำคัญจริง ไม่ใช่เรื่องรสนิยม:
- emoji **หน้าตาต่างกันทุกเครื่อง** (iOS/Android/รุ่น OS) → คุมแบรนด์ไม่ได้เลย
- emoji **เปลี่ยนสีตามธีมไม่ได้** → ทำ active/inactive state ไม่ได้
- emoji มีรายละเอียดเยอะและสีจัด → ชนกับลุคพาสเทลสงบโดยตรง

**แทนด้วย:** SVG เส้น (`react-native-svg`) — stroke 2, ปลายมน (`strokeLinecap="round"`), รับ prop สีได้

## 4. เช็กลิสต์ก่อนส่ง

- [ ] ไม่มี emoji เป็นไอคอน (ใช้ SVG)
- [ ] ทุกอย่างที่กดได้มี press feedback (scale 150ms)
- [ ] พื้นที่แตะ ≥ 44×44
- [ ] คอนทราสต์ตัวอักษร ≥ 4.5:1
- [ ] ตัวอักษรเนื้อความ ≥ 16px
- [ ] เคารพ `prefers-reduced-motion`
- [ ] ไม่มีสีนีออน / gradient ม่วง-ชมพูแบบ AI
- [ ] ไม่มี dark mode (กฎ Wellness — เอาไว้ทีหลังถ้าต้องการ)
- [ ] ข้อมูลไม่พอ → ชวนกรอก ห้ามโชว์ 0 หรือเดา
