Mommunjai — Flow & Journey สำหรับตรวจรับ

เอกสารนี้แสดง เส้นทางการใช้งานจริง และ หน้าจอจำลองด้วยสีจริงของแบรนด์ ทั้ง 3 ฝั่ง เพื่อให้ทีมครูก้อยตรวจและยืนยันก่อนเปิดใช้งานจริง — กดปุ่มแต่ละขั้นตอนเพื่อดูหน้าจอที่เกี่ยวข้อง

CI จริง: เขียว #1BC0BA · ชมพู #F978B3 ฟอนต์: Poppins + Prompt สถานะ: รอยืนยันจากทีมครูก้อย

👩 ฝั่งลูกค้า — ผู้หญิงที่อยากมีลูก / เตรียมตั้งครรภ์

เข้ามาจากเพจ/เว็บ/โฆษณา → ใช้เครื่องมือฟรี → ได้แผนเฉพาะตัว → เข้าสู่ LINE OA

🎯 เป้าหมาย: ให้คุณค่าก่อน (เครื่องมือ+ความรู้) แล้วจึงเปลี่ยนเป็น lead ที่ทีมรู้จักตัวตน — ไม่ใช่หน้าร้านขายของ

เส้นทางการใช้งาน (กดเพื่อดูหน้าจอ)

👩‍💼 ฝั่งทีมงาน — แอดมิน LINE OA / ทีมขาย

เข้าระบบด้วย PIN → ดูรายชื่อผู้ลงทะเบียน → เปิดโปรไฟล์รายคน → คุยต่อใน LINE ได้ตรงจุด

🎯 เป้าหมาย: รู้ทันทีว่าคนที่ทักมาคือใคร อยู่ช่วงไหน สนใจอะไร — ไม่ต้องถามซ้ำ

เส้นทางการทำงาน (กดเพื่อดูหน้าจอ)

🧑‍💼 ฝั่งผู้ดูแลระบบ — หัวหน้าทีม / เจ้าของแบรนด์

ตั้งค่าผู้ดูแลคนแรก → สร้างบัญชีให้ทีม → กำหนดสิทธิ์รายคน → ดูข้อมูลได้ทุกส่วน

🎯 เป้าหมาย: คุมได้ว่าใครเห็นอะไร (ข้อมูลสุขภาพลูกค้าเป็นข้อมูลอ่อนไหวตาม PDPA)

เส้นทางการดูแลระบบ (กดเพื่อดูหน้าจอ)

✅ เช็กลิสต์สำหรับยืนยัน

รบกวนทีมครูก้อยตรวจแต่ละข้อ แล้วแจ้งกลับว่า ผ่าน หรือ ขอแก้ ตรงไหน

⏳ เรื่องที่ยังรอทีมครูก้อยยืนยัน (มีผลต่อการเปิดใช้จริง)
  • เลข อย. / ฆอ. ของสินค้า — ต้องมีก่อนแสดงสรรพคุณในแอปหรือโฆษณา
  • ไฟล์โลโก้แบบ vector (.ai/.svg) — ตอนนี้ใช้ไฟล์ PNG ทางการแล้ว (คมชัดพอสำหรับเว็บ/แอป) ขอ vector เพิ่มสำหรับงานพิมพ์
  • เกณฑ์คะแนนในรายงาน — ทีมพัฒนาตั้งค่าเริ่มต้นไว้ ขอให้เภสัชกร/ผู้เชี่ยวชาญตรวจก่อนใช้จริง
  • นโยบายความเป็นส่วนตัวฉบับสมบูรณ์ — ปัจจุบันเป็นฉบับร่าง
  • ชื่อกลุ่มผลิตภัณฑ์เด็ก — เว็บใหม่เขียนไม่ตรงกัน (BLOOM หรือ BABY)
