🔧 รายการที่เคยไม่ผ่าน — แก้แล้วทั้งหมด (1 เคส)

  1. TC-11-01 — “ให้นมบุตร” เคยยังเจอคำถาม “เข้าสู่กระบวนการทางการแพทย์ไหมคะ?” — ✅ แก้แล้ว 31/7
    สเปก R11 สั่งให้ตัดขั้น ART ออกจาก lactating เหมือนที่ทำกับ prep แต่โค้ดตัดออกเฉพาะ prep: app/plan/page.tsx บรรทัด 34 → if (s === "art") return stage !== "prep";
    หลักฐานจริง: เดิน /plan?stage=lactating จนจบ — แถบความคืบหน้าขึ้น “อีก 4 ขั้นตอน” (5 ขั้น = intro/name/health/art/contact) และหน้าจอที่ 4 คือ “เข้าสู่กระบวนการทางการแพทย์ไหมคะ?” พร้อมข้อความรอง “ถามเพื่อจัดแผนบำรุงไข่/ผนังมดลูก…” (เทียบกับ ?stage=prep ที่ขึ้น “อีก 3 ขั้นตอน” และไม่มีหน้าจอนี้ = ยืนยันว่ากฎถูกใส่ไว้แค่ prep จริง)
    ผลกระทบต่อเนื่อง (สังเกตจริงในรายงานที่ออกมา):
    • แม่ให้นมเลือก “IVF-ICSI” หรือ “เตรียมผนังมดลูก” ได้ → tier = full ทันที ทั้งที่ตามดีไซน์กลุ่มนี้ควรเป็น teaser เสมอ (คอมเมนต์ใน lib/report.ts บรรทัด 484 เขียนไว้เองว่า “หลัง R5/R11 ตัดคำถาม ART ออกจาก prep/lactating → 2 กลุ่มนี้เป็น teaser เสมอ” ซึ่งตอนนี้ไม่จริง)
    • เมื่อ artPlan ≠ “ยัง” ระบบเติม A.O.S เข้าไปในแผนของแม่ให้นม พร้อมข้อความ “ดูแลคุณภาพไข่และตัวอ่อน” และหัวข้อแผนเปลี่ยนเป็น “บำรุงไข่ให้พร้อมก่อนเข้าสู่กระบวนการ” (เห็นจริงในรายงาน MJ-KM9B6R ที่ทดสอบ)
    • ถ้าเลือก “เตรียมผนังมดลูก” จะได้ชุด LINING_PREP_SET = Colla Telo + ดอกคำฝอย + น้ำมันละหุ่ง + probiotic ซึ่งทั้งดอกคำฝอย/น้ำมันละหุ่งไม่มี stop.lactating จึงผ่าน Safety Matrix เข้าไปอยู่ในแผนของแม่หลังคลอดได้
    ทางแก้ที่เล็กที่สุด: if (s === "art") return stage !== "prep" && stage !== "lactating"; (แนะนำเพิ่ม unit test ล็อก stepsFor() ทั้ง 5 stage ด้วย — ตอนนี้ยังไม่มีเทสต์ตัวไหนแตะฟังก์ชันนี้เลย จึงหลุดมาถึงรอบนี้)

TC-05-03 — “stage=prep ส่งข้อมูลจบ แล้วเช็คค่า art_plan ที่บันทึกลงระบบ”

เหตุผล: เครื่องนี้ไม่มีไฟล์ .env.local และไม่มีค่า SUPABASE_URL / SUPABASE_SERVICE_ROLE_KEY → /api/lead เข้าเงื่อนไข if (!hasSupabaseEnv()) แล้วคืน dev_mode: true โดย ไม่เคยรัน INSERT ลงตาราง leads เลย จึงไม่มีแถวจริงให้ตรวจค่า

สิ่งที่ยืนยันได้ (แต่ยังไม่ใช่การเห็นค่าที่บันทึกจริง): state ตั้งต้นของฟอร์มคือ art_plan: "ยัง" (app/plan/page.tsx บรรทัด 59-62) · ฝั่ง API เขียน art_plan: mapLegacyArtPlan(body.art_plan) ซึ่งคืน "ยัง" · และผลข้างเคียงที่สังเกตได้จริงคือ prep ได้ tier = teaser ซึ่งเป็นค่าที่คำนวณจาก artPlan = "ยัง"

สิ่งอื่นที่ตรวจไม่ได้ (ไม่ได้อยู่ในเลข 64 เคส แต่ต้องรู้ก่อนขึ้นจริง):
