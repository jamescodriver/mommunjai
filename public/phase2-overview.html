🅰️ ส่วน A — CRM & Base Reactivation

สเปกเต็มอยู่แล้วที่ docs/PRD-PHASE3.md — เปลี่ยนฐาน LINE OA 150,000 คนให้ใช้งานได้จริงเป็น CRM (ระบบบริหารความสัมพันธ์ลูกค้า)

Epic D

Identity Resolution

เปลี่ยนผู้ติดตามนิรนาม (150,000 คน) → ลูกค้าที่รู้จัก โดยเริ่มจากช่องทางที่ไม่เสียค่าข้อความก่อน

  • P0 · LIFF Connect — เปิดจาก LINE แล้วรู้ตัวตนทันที ไม่ต้องพิมพ์อะไร
  • P0 · Rich Menu 2 แบบ — เมนู "ยังไม่รู้จัก" vs "รู้จักแล้ว" สลับอัตโนมัติ
  • P0 · ขยาย Webhook รับ follow/unfollow/message/postback
  • P0 · ดึงฐานผู้ติดตามเดิม 150,000 คน แบบประหยัด (lazy — ดึงโปรไฟล์เฉพาะตอนมีปฏิสัมพันธ์จริง)
  • P0 · ช่องทางเก็บ lead ที่ไม่เสียเงิน (เมนูล่าง/คีย์เวิร์ด/VOOM/QR นอก LINE)
  • P1 · ทดสอบยิงกลุ่มเล็กเพื่อวัดราคาต่อหัว (ต้องอนุมัติก่อนยิงจริง)
❓ คำถามที่ยังบล็อกอยู่:
  • ใครเป็นเจ้าของ LINE Login channel/LIFF app (ต้องอยู่ใต้บัญชีแบรนด์) — บล็อกจริง
  • ราคาต่อข้อความจริง + แพ็กเกจ OA ปัจจุบัน
  • นโยบายความเป็นส่วนตัวฉบับเต็ม (ใช้ CRM + ส่งการตลาด) ใครอนุมัติ
🧑‍💼
Epic E

Customer 360

แอดมินเปิดดูลูกค้าคนหนึ่งแล้ว "เข้าใจเขาได้ใน 10 วินาที" ก่อนพิมพ์ตอบใน LINE

  • P0 · หน้าโปรไฟล์ลูกค้า 4 บล็อก: หัวการ์ด + ไทม์ไลน์ + โน้ตทีม + แผงลงมือ (รวมดาวน์โหลด/ลบข้อมูลตาม PDPA)
  • P0 · ยกระดับ /leads → /crm/customers พร้อมตัวกรอง + เลือกหลายรายการสร้างกลุ่มได้
  • P0 · แดชบอร์ดสุขภาพฐาน — รู้จักแล้วกี่ % · เพิ่มใหม่/บล็อก · โควตาข้อความเดือนนี้
❓ คำถามที่ยังบล็อกอยู่:
  • ทีมแอดมินกี่คน ต้องแบ่งเจ้าของลูกค้าจริงไหม
🎯
Epic F

Segment → Audience → Campaign

ยิง 800 คนที่ใช่ ดีกว่ายิง 150,000 คนมั่ว — และรู้ต้นทุนก่อนกดส่งเสมอ

  • P0 · เพดานบังคับด้วยโค้ด: 5,000 คน/แคมเปญ + เพดานงบรายเดือน (ปิดปุ่มส่งจริง ไม่ใช่แค่เตือน)
  • P0 · ตัวสร้างกลุ่ม (เงื่อนไข AND/OR) + นับจำนวนคนแบบสด + ตัดคนที่บล็อก/ไม่ยินยอมออกอัตโนมัติ
  • P0 · ส่งกลุ่มเข้า LINE เป็น Audience (ใช้ได้ทั้งระบบเราและ OA Manager)
  • P0 · ตัวเขียนแคมเปญ 3 ขั้น + ตัวตรวจคำต้องห้ามอัตโนมัติ + บังคับส่งทดสอบก่อนเสมอ
  • P0 · ผลลัพธ์รายคนผูกกลับเข้าไทม์ไลน์ลูกค้า
❓ คำถามที่ยังบล็อกอยู่:
  • จะแชร์ประวัติสั่งซื้อเข้าระบบไหม (เปิดกลไก "เตือนซื้อซ้ำ" ได้ถ้าใช่)
🔁
Epic G

Lifecycle Automation

ส่งของที่มีประโยชน์ "ถูกเวลา" โดยไม่ใช้แรงคน — และไม่รบกวน

  • P1 · เครื่องยนต์ journey: ทริกเกอร์ → เงื่อนไข → รอ → ส่ง → เงื่อนไขหยุด (หยุดทันทีถ้าลูกค้าทักมาเอง)
  • P1 · 5 journey ชุดแรก: ยังไม่เปิดรายงาน · เช็คอิน 30/60/90 วัน · เตือนหน้าต่างไข่ตก · ปลุกคนเงียบ 60 วัน · ชวนคู่
  • 🚫 ข้อห้ามเชิงจริยธรรม: ห้ามส่งอัตโนมัติเรื่องผลตั้งครรภ์/แท้ง/รอบเดือนแบบตีความว่าล้มเหลว ทุก journey ต้องผ่าน red-team ก่อนเปิด
❓ คำถามที่ยังบล็อกอยู่:
  • เก็บเนื้อความแชทไหม (ค่าเริ่มต้นที่เสนอ: ไม่เก็บ)
