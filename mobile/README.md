# Mommunjai Mobile — รุ่นทดลอง (ยังไม่ปล่อยขึ้นร้าน)

แอปมือถือต่อยอดจากเว็บ Mommunjai · React Native (Expo) · iOS + Android
สเปกเต็ม: [`../docs/mobile/PRD-MOBILE-APP.md`](../docs/mobile/PRD-MOBILE-APP.md)

---

## 📱 เปิดเล่นบนมือถือ (ใช้เวลา ~2 นาที)

### 1) ลง Expo Go บนมือถือ
- **iPhone:** App Store → ค้น **"Expo Go"**
- **Android:** Play Store → ค้น **"Expo Go"**

### 2) เปิดเซิร์ฟเวอร์ที่เครื่อง Mac
```bash
cd mobile && npx expo start
```

### 3) ต่อมือถือ
**มือถือกับ Mac ต้องอยู่ Wi-Fi วงเดียวกัน**
- **iPhone:** เปิดกล้อง → สแกน QR ที่ขึ้นใน terminal → กดแถบที่เด้งขึ้นมา
- **Android:** เปิดแอป Expo Go → กด **Scan QR code** → สแกน

ถ้าสแกนไม่ได้ ให้เปิด Expo Go → **Enter URL manually** → พิมพ์ `exp://<IP ของ Mac>:8081`
(ดู IP ด้วย `ipconfig getifaddr en0`)

> **Wi-Fi คนละวงหรือใช้ไม่ได้?** ลอง `npx expo start --tunnel` แทน (ช้ากว่าแต่ข้ามเครือข่ายได้
> ต้องมีเน็ต · ถ้า ngrok ล่มจะใช้ไม่ได้ชั่วคราว)

## ⏳ ยังไม่มีในรุ่นนี้ (รอคำตอบ Open Question ใน PRD)

- **การแจ้งเตือน (push)** — รอเคาะ A1 · เป็นเหตุผลหลักที่ทำแอป ต้องมีก่อนส่งขึ้นร้านจริง
- **ผูกบัญชี LINE / ส่งข้อมูลขึ้น server** — รอ LINE Login channel (A4) · **ตอนนี้ข้อมูลอยู่ในเครื่องเท่านั้น**
- **แผนฉบับเต็มในแอป** — รอเคาะ B1 · ตอนนี้ทำเหมือนเว็บ (ต้องผ่าน LINE OA) เพื่อไม่เปลี่ยน funnel เดิมโดยพลการ
- เครื่องมืออีก 4 ตัว (เช็กสารอาหาร · ออกกำลังกาย · แนะนำวิตามิน · ค่าตรวจ · ความเครียด)
- เนื้อหา "ความรู้ของวันนี้" — รอเคาะ B2 ว่าเนื้อหามาจากไหน

## 🔧 โครงสร้างโค้ด

```
mobile/
  App.tsx              โครงแอป + bottom tabs + state กลาง
  metro.config.js      🔑 ตั้ง alias @shared → ../lib (โค้ดคำนวณชุดเดียวกับเว็บ)
  src/
    theme.ts           สี/ตัวอักษรตาม CI จริง (docs/DESIGN.md)
    store.ts           เก็บข้อมูลในเครื่อง (AsyncStorage)
    rhythm.ts          "จังหวะวันนี้" + งานประจำวัน แยกตามช่วงชีวิต
    components/ui.tsx  ปุ่ม การ์ด ช่องติ๊ก แถบความคืบหน้า
    screens/           Onboarding · Today · Tools · Plan · Me
```

### 🔴 กฎที่ห้ามผิด (มีคอมเมนต์กำกับในโค้ดทุกจุด)

1. **โค้ดคำนวณห้าม copy มาไว้ในแอป** — ใช้ `@shared/calc/*` ซึ่งชี้ไปที่ `lib/` ของเว็บ
   ถ้าแยกเป็น 2 ชุด Safety Matrix (กฎว่าสินค้าไหนห้ามใช้ช่วงไหน) จะหลุดจากกันได้ = อันตรายจริง
2. **checklist รายวันห้ามเป็นสินค้า** — ต้องเป็นพฤติกรรมเท่านั้น
3. **คำเตือน "ใช้คุมกำเนิดไม่ได้"** ต้องอยู่ทุกที่ที่พูดถึงวันไข่ตก
4. **service_role key ห้ามเข้าแอป** — แอปที่ติดตั้งบนเครื่องผู้ใช้ไม่มีความลับ

### คำสั่งที่ใช้บ่อย
```bash
npx expo start          # เปิดเซิร์ฟเวอร์ (สแกน QR ด้วยมือถือ)
npx expo start --tunnel # กรณี Wi-Fi คนละวง
npx tsc --noEmit        # ตรวจ type
```
