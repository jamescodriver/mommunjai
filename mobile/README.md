# Mommunjai Mobile — รุ่นทดลอง (ยังไม่ปล่อยขึ้นร้าน)

แอปมือถือต่อยอดจากเว็บ Mommunjai · React Native (Expo) · iOS + Android
· สเปกฟีเจอร์: [`../docs/mobile/PRD-MOBILE-APP.md`](../docs/mobile/PRD-MOBILE-APP.md)
· สเปกงานออกแบบ: [`../docs/mobile/DESIGN-MOBILE.md`](../docs/mobile/DESIGN-MOBILE.md) (แนว 2D โค้งมน อ้างอิง FLO)

## 📱 เปิดเล่นบนมือถือ (ใช้เวลา ~2 นาที)

### 1) ลง Expo Go บนมือถือ
- **iPhone:** App Store → ค้น **"Expo Go"**
- **Android:** Play Store → ค้น **"Expo Go"**

### 2) เปิดเซิร์ฟเวอร์ที่เครื่อง Mac
```bash
cd mobile && npx expo start
```

### 3) ต่อมือถือ
**มือถือกับ Mac ต้องอยู่ Wi-Fi วงเดียวกัน**
- **iPhone:** เปิดกล้อง → สแกน QR ที่ขึ้นใน terminal → กดแถบที่เด้งขึ้นมา
- **Android:** เปิดแอป Expo Go → กด **Scan QR code** → สแกน

ถ้าสแกนไม่ได้ ให้เปิด Expo Go → **Enter URL manually** → พิมพ์ `exp://<IP ของ Mac>:8081`
(ดู IP ด้วย `ipconfig getifaddr en0`)

> **Wi-Fi คนละวงหรือใช้ไม่ได้?** ลอง `npx expo start --tunnel` แทน (ช้ากว่าแต่ข้ามเครือข่ายได้
> ต้องมีเน็ต · ถ้า ngrok ล่มจะใช้ไม่ได้ชั่วคราว)

## 🎫 ตอนจบ: รายงานเบื้องต้น → ออก ticket → ไป LINE OA

แท็บ **"แผนของฉัน"** → ปุ่มล่างสุด เปิดหน้า `src/screens/Handoff.tsx`

```
กรอกชื่อเล่น + ช่องทางติดต่อ + ติ๊กยินยอม (PDPA)
        ↓  POST /api/lead   (src/lead.ts)
รหัส MJ-XXXXXX + รายงานเบื้องต้น (เป้าหมายต่อวัน · แนะนำเบื้องต้น · คำเตือน)
        ↓
ปุ่มเปิด LINE OA → พิมพ์รหัสในแชท → รับแผน 90 วันฉบับเต็ม
```

ใช้ **API + ฐานข้อมูลตัวเดียวกับเว็บ** — lead จากแอปกับจากเว็บไหลเข้าที่เดียวกัน
แอดมินแยกออกด้วย tag `mobile-app` ที่ติดมากับทุก lead จากแอป

### 🔴 กฎที่ห้ามผิดในเส้นทางนี้

| กฎ | เหตุผล |
|---|---|
| **ไม่ยินยอม = ไม่ส่ง** | ข้อมูลสุขภาพเป็นข้อมูลอ่อนไหว (PDPA ม.26) ใช้ `CONSENT_TEXT` ชุดเดียวกับเว็บผ่าน `@shared/disclaimer` **ห้ามเขียนข้อความเอง** เพราะ `consent_log` เก็บเวอร์ชันไว้ตรวจย้อน |
| **ห้ามคำนวณแผนฉบับเต็มในเครื่องแล้วโชว์** | ทำได้จริง (`@shared/report` เรียกได้) แต่ต้นเคาะ 1 ส.ค. 2569 ว่าแผนเต็มต้องผ่าน LINE OA เท่านั้น · ถ้าแอปโชว์เอง = เปิดประตูหลังให้ funnel พังทั้งที่เว็บยังปิดอยู่ |
| **คำเตือนต้องอยู่เหนือปุ่มไป LINE** | กฎจาก red-team ของเว็บ (31/7) — ไม่งั้นผู้หญิงอายุ 40+ เห็นรายการสินค้า + ปุ่มขาย โดยไม่เคยเห็นประโยค "พบแพทย์ผู้เชี่ยวชาญได้เลย" |
| **`API_BASE_URL` ต้องเป็น deployment เดียวกับที่ LINE webhook ชี้ไป** | ticket ถูกเขียนลง Supabase ของ deployment นั้น · ถ้าคนละตัว ผู้ใช้พิมพ์รหัสแล้วบอทตอบ "ไม่พบรหัสนี้" (ตั้งที่ `src/config.ts`) |
| **"ลบข้อมูลทั้งหมด" ห้ามพูดเกินจริง** | ปุ่มนั้นลบได้แค่ของในเครื่อง · ถ้าเคยส่งไปแล้วต้องบอกและชี้ทางขอลบจริงผ่าน LINE |

> ⚠️ **การกดส่งจริงจะสร้าง lead จริงในฐานข้อมูลของลูกค้า** — เวลาเทสต์ให้ใช้ชื่อที่รู้ว่าเป็นของทดสอบ แล้วลบทีหลังที่หน้า `/leads` ของเว็บ

## ⏳ ยังไม่มีในรุ่นนี้ (รอคำตอบ Open Question ใน PRD)

- **การแจ้งเตือน (push)** — รอเคาะ A1 · เป็นเหตุผลหลักที่ทำแอป ต้องมีก่อนส่งขึ้นร้านจริง
- **ผูกบัญชี LINE (LIFF)** — รอ LINE Login channel (A4) · **ไม่จำเป็นสำหรับการเก็บ lead** เพราะใช้ทางเดียวกับเว็บคือรหัส ticket
- **แผนฉบับเต็มในแอป** — รอเคาะ B1 · ตอนนี้ทำเหมือนเว็บ (ต้องผ่าน LINE OA) เพื่อไม่เปลี่ยน funnel เดิมโดยพลการ
- **ผลเครื่องมือที่ตอบสด ๆ ยังไม่ถูกส่งไปกับ lead** — ส่งไปเฉพาะ `ovulation` ตัวเดียว เพราะเป็นตัวเดียวที่ input ถูกเก็บในโปรไฟล์จริง · เครื่องมืออื่น (เช็กสารอาหาร/ความเครียด/ออกกำลังกาย) ต้องเก็บผลลงเครื่องก่อน เป็นงานคนละก้อน · **ห้ามปลอมค่ามาเติม**
- เนื้อหา "ความรู้ของวันนี้" — รอเคาะ B2 ว่าเนื้อหามาจากไหน

> ⚠️ **ปฏิทินเลือกวันใช้ native module** (`@react-native-community/datetimepicker`) จึง**ไม่แสดงบน Expo web**
> (บนเว็บมีช่องพิมพ์สำรองให้แทน) — ต้องทดสอบบนมือถือ/simulator จริงเท่านั้น

    store.ts           เก็บข้อมูลในเครื่อง (AsyncStorage)

### 🔴 กฎที่ห้ามผิด (มีคอมเมนต์กำกับในโค้ดทุกจุด)

0. **ห้ามใช้ emoji เป็นไอคอน** — ใช้ SVG ใน `src/components/icons.tsx`
   (emoji หน้าตาต่างกันทุกเครื่อง เปลี่ยนสีตามธีมไม่ได้ และชนกับลุคพาสเทล)
1. **โค้ดคำนวณห้าม copy มาไว้ในแอป** — ใช้ `@shared/calc/*` ซึ่งชี้ไปที่ `lib/` ของเว็บ
   ถ้าแยกเป็น 2 ชุด Safety Matrix (กฎว่าสินค้าไหนห้ามใช้ช่วงไหน) จะหลุดจากกันได้ = อันตรายจริง
2. **checklist รายวันห้ามเป็นสินค้า** — ต้องเป็นพฤติกรรมเท่านั้น
3. **คำเตือน "ใช้คุมกำเนิดไม่ได้"** ต้องอยู่ทุกที่ที่พูดถึงวันไข่ตก
4. **service_role key ห้ามเข้าแอป** — แอปที่ติดตั้งบนเครื่องผู้ใช้ไม่มีความลับ
